What is Agent Platform supervised fine-tuning (SFT) service with a dataset of valid MechScript examples. 
Out of the box, foundational LLMs (like Gemini or PaLM) know popular languages like Python, Java, or SQL because they were trained on massive amounts of public code. However, they have zero knowledge of a company's private, internal language like "MechScript."
Supervised Fine-Tuning (SFT) is the process of taking a pre-trained foundational model and training it further on a highly specific, curated dataset of prompt-response pairs. In this scenario, you would provide the model with hundreds or thousands of examples of user requests paired with the correct, valid MechScript code.

When dealing with a completely unseen syntax, format, or domain-specific language (DSL), SFT is the most effective approach because:
* It alters the model's behavior: Unlike providing documents for the model to read, SFT actually updates the model's weights slightly so it internalizes the vocabulary, grammar, and syntax rules of MechScript.
* Overcomes Context Limits: You could try to put the rules of MechScript in the system prompt (Few-Shot Prompting), but complex language rules would quickly exhaust the context window and the model would likely still hallucinate syntax errors. SFT bakes the syntax into the model itself.


Use the Agent Platform SDK to create a Ray on Agent Platform cluster. Update the script to use Ray Data libraries for distributed processing, and submit the job to the cluster.  => USE WHEN OOM or OUT OF MEMORY ISSUES OCCUR 
Ray is a popular open-source framework used to scale Python and machine learning workloads from a single machine to a massive cluster of machines. Ray on Vertex AI is Google Cloud's fully managed service for this framework. Instead of manually provisioning Compute Engine VMs, installing Ray, and networking them together, you use the Vertex AI SDK to spin up a fully configured Ray cluster instantly.

Standard Python libraries like pandas are designed to run on a single machine's CPU and memory. Even if you spin up a 10-node cluster, a standard pandas script won't know how to use the other 9 nodes.
Ray Data is a distributed data processing library native to Ray. By updating your script to use Ray Data, you tell the framework how to split the massive dataset into smaller chunks (partitions) and process them in parallel across all the nodes in the cluster.
